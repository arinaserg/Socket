# Socket
C++ socket wrapper: OOP hierarchy for Stream/Datagram sockets and SocketAddress (AF_INET/AF_UNIX).

Реализовать две иерархии классов: 	Socket (для дескрипторов сокетов) и 
SocketAddress (для адресов сокетов в разных доменах). 
Класс SocketAddress представляет собой интерфейс сокетного адреса для разных доменов и содержит три абстрактные операции: 

    	virtual int getLength() const= 0; // длина адреса
      
   	    virtual short getDomain() const = 0; // AF_INET, AF_UNIX, ....
    
    	virtual const struct sockaddr* getAddr() const = 0; 
      
В файле SocketAddress.hpp задано описание класса SocketAddress и «заготовки» двух конкретных классов–наследников: 

- UnixSocketAddress // для реализации адресов в домене AF_UNIX 
- InetSocketAddress // для реализации адресов в домене AF_INET

Класс Socket представляет сокетный дескриптор и содержит ЗАЩИЩЕННЫЙ конструктор, а также две абстрактные операции 

	virtual bool isStream() = 0;
  
	virtual bool isDatagram() = 0;
  
Эти операции следует реализовать в производных классах. Дополнительно ничего в этом классе добавлять и реализовывать не надо.
Класс StreamSocket наследуется от Socket. Он также имеет защищенный конструктор, что сделано для того, чтобы класс можно было использовать только при наследовании.  Конструктор создает сокет для потокового соединения.  В классе следует реализовать операции:

  	- isStream () и
    
  	- isDatagram() . 
    
Дополнительно ничего в этом классе добавлять и реализовывать не надо.

Классы ClientStreamSocket и ServerSocket наследуются от StreamSocket. 

В классе ClientStreamSocket  надо реализовать операцию Connect() и дополнить его перегрузками методов Write() и Read(). 

Класс ServerSocket является абстрактным. Предполагается, что при возникновении некоторого события происходит вызов абстрактного защищенного метода, который является реакцией на событие. В нашем случае событие – это прием запроса на соединение от клиента, и метод-реакция называется OnAccept().

Для использования класса ServerSocket нужно унаследовать от него новый класс и заместить в нем метод OnAccept(), в теле которого осуществляется взаимодействие с клиентом. Методу OnAccept() передается указатель на экземпляр класса ClientStreamSocket, через который осуществляется взаимодействие с клиентом

Пример сервера, использующего класс ServerSocket, включая вызов метода Accept() и замещение метода OnAccept(), приведен в файле Server.cpp. Текст его клиента – в файле client.cpp.

Класс DatagramSocket используется для организации взаимодействия по протоколу UDP. Для него надо реализовать все методы чтения/записи. Для зачета задания реализация этого класса не обязательна, как и программы-тесты для протокола UDP. Но реализация класса и содержательные примеры его использования приветствуются и будут вознаграждены бонусом(3).
